# Operación — digitalización de muestras

El servicio debe estar instalado por IT y el entorno de ensayo habilitado. Durante el piloto, todos los resultados se revisan por una persona.

1. Abrir INDEX con la cuenta corporativa. En **Muestras → Sample Digitization**, crear un lote con nombre y división correctos. Un lote equivale a una sesión de trabajo para medir productividad.
2. Confirmar en el dashboard que el motor tiene señal reciente. Si no, se pueden subir imágenes, pero permanecerán pendientes hasta que IT inicie el worker.
3. En **Capturar / importar**, abrir cámara, encuadrar la etiqueta completa, evitar sombras/reflejos y capturar. La confirmación indica que la imagen quedó en la cola local; el contador «pendientes de envío local» debe llegar a cero antes de borrar datos del navegador o cambiar de equipo. No esperar al reconocimiento para fotografiar la siguiente muestra.
4. La captura automática es experimental y debe activarse expresamente. Cambiar la etiqueta después de cada confirmación. Si se bloquea una imagen parecida, cambiar el encuadre y capturar manualmente; nunca asumir que dos muestras técnicamente parecidas son una sola.
5. Para importación, seleccionar archivos, carpeta o arrastrar fotografías/ZIP. JPG, PNG, WEBP y HEIC/HEIF; máximo 20 MiB por imagen y 24 megapíxeles en el motor. Los errores se muestran por separado. Un rechazo permanente de subida queda conservado con su nombre y error; las demás imágenes siguen avanzando. «Reintentar envíos» vuelve a intentar los archivos conservados. Para ZIP grandes, dividir grupos; no incluir documentos ni otros archivos. El archivo rechazado no impide procesar los demás.
6. En **Revisión**, filtrar estados y fechas (filtros de día en UTC), abrir un registro. Revisar imagen procesada, original, texto, advertencias y confidencias. Al enfocar un campo aparece su fragmento de origen. Alt + flecha derecha avanza por la página de registros cargada; los controles también funcionan con Tab y Enter.
7. Corregir solo información verificable. Si falta evidencia, dejar el campo vacío y guardar para revisión. Los campos personalizados se agregan con nombre y valor; quedan marcados como intervención humana sin confianza OCR inventada. La nota de revisión es obligatoria para validar, rechazar o confirmar duplicado.
8. En **Posibles coincidencias → Comparar**, ver ambas fotografías originales, campos coincidentes, diferencias y campos de confianza insuficiente. Guardar correcciones antes de comparar. Elegir **Fotografía repetida**, **Misma muestra confirmada**, **Variante legítima**, **Muestras distintas** o **Pendiente de decisión**, siempre con motivo. Las dos primeras marcan Duplicate; las demás dejan Needs Review para validar los campos por separado. Ninguna opción elimina ni fusiona registros. Un código compartido o una apariencia similar no prueba identidad física. Si no es legible, rechazar o volver a fotografiar; reprocesar puede ayudar a un fallo técnico, no recuperar texto físicamente ausente.
9. El vínculo opcional con producto utiliza el UUID de un producto existente y solo acepta la misma división. IT/PD puede ayudar a encontrarlo. No se crean existencias ni movimientos de inventario a partir de fotografías.
10. Exportar CSV, Excel o JSON de todo el lote o filtros; activar «solo selección» o «solo validados» cuando corresponda. JSON conserva trazabilidad técnica; CSV/Excel son tablas de campos. Las imágenes permanecen privadas y no se incrustan en exportaciones.

**Estados:** Pending espera imagen confirmada/worker; Processing está asignado; Needs Review requiere decisión; Validated tiene revisión humana; Duplicate indica una repetición confirmada por una persona; los registros anteriores a esta actualización conservan su estado histórico (consultar nota/historial); Failed registra error; Cancelled se retiró de cola; Rejected no se aceptó. Pausar afecta nuevas asignaciones, no interrumpe las activas. Cancelar un trabajo activo invalida su resultado aunque el motor termine después.

**Si se corta la conexión:** conservar el navegador y abrir nuevamente el mismo módulo/cuenta. Usar «Reintentar envíos». Si ya se había confirmado la subida, el trabajo está en Supabase y puede continuar sin el navegador. No abrir una segunda cuenta para recuperar la cola de otra persona. Si se borra IndexedDB antes del envío, es necesario reimportar la fotografía.

**Precisión:** el porcentaje OCR describe caracteres; el de interpretación describe la regla aplicada. Ninguno certifica la veracidad textil. En el piloto no se salta la revisión por confianza alta. El dashboard compara valores iniciales contra los validados, no sustituye una evaluación independiente.
